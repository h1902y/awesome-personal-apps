# Personal apps (all apps)

Every personal app from the h1902y Library in one plugin, version 1.0.0. Each app is a skill that runs on files you share, such as a help desk export or meeting notes, and sends nothing anywhere. New apps arrive with each update, so turn on auto-update for the marketplace.

**Pick one:** install this plugin or the single apps, not both. With both, the same skill shows twice.

## Apps

- `weekly-ticket-summary`: Drop last week's help desk export into Claude and get the themes, counts and urgent tickets your team should read first.
- `meeting-actions-to-owners`: Paste raw meeting notes into Claude and get every action with one owner, the gaps flagged and a follow-up drafted for each person.
