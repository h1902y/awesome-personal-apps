# Awesome personal apps

Small AI apps for one weekly task: each one is a Claude skill, a prompt and sample data, so you can try it today without touching real work data. Free to use at work.

## Install any app in Claude Code

```
/plugin marketplace add h1902y/awesome-personal-apps
/plugin install <app-name>@personal-apps
```

Every app at once: `/plugin install personal-apps@personal-apps` (new apps arrive with its updates). Install either single apps or the bundle, not both: with both, each skill shows twice.

## Install in Codex

```
codex plugin marketplace add h1902y/awesome-personal-apps
codex plugin add <app-name>@personal-apps
```

## Install in Claude (web or desktop app)

In Claude, go to **Customize > Plugins**, choose **Add > Add marketplace** and enter `h1902y/awesome-personal-apps`. Then choose **Add** on the app you want, and turn on **Sync automatically** for the marketplace to get new versions. The app's script needs **Code execution** on in **Settings > Capabilities**; on a Team or Enterprise plan, an Owner may need to allow adding marketplaces first.
