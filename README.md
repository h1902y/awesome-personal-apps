# Awesome personal apps

Small AI apps for one weekly task: each one is a Claude skill, a prompt and sample data, so you can try it today without touching real work data. Free to use at work.

## Install any app in Claude Code

```
/plugin marketplace add h1902y/awesome-personal-apps
/plugin install <app-name>@personal-apps
```

In Claude (web or desktop), download the app's `-skill.zip` from its repo, then go to **Customize > Skills > + > Create skill > Upload a skill** and turn it on. Works on any plan, Free included; Code execution must be on in Settings > Capabilities.

## Apps

### Support

- [Weekly ticket summary](https://github.com/h1902y/weekly-ticket-summary): Drop last week's help desk export into Claude and get the themes, counts and urgent tickets your team should read first. ### Product and project

- [Meeting actions to owners](https://github.com/h1902y/meeting-actions-to-owners): Paste raw meeting notes into Claude and get every action with one owner, the gaps flagged and a follow-up drafted for each person. ([page](https://h1902y.com/library/meeting-actions-to-owners?utm_source=github&utm_medium=index&utm_campaign=library))
